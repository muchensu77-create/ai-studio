# AI 创新工作室 · 展示页

线上地址：https://muchensu77-create.github.io/ai-studio/

广州职业技术大学智慧汽车学院 AI 创新工作室的纳新展示页，分七章介绍工作室在做的事：软件与系统开发、AI 智能体与工作流、AI 影视、工科计算与建模、量化投资、科研项目、竞赛获奖。

## 操作

- 翻页：↓ / → / 空格 / PageDown 下一章，↑ / ← / PageUp 上一章，滚轮一次翻一章
- 全屏：F
- 点任意一部短片看完整版（有声音）

## 本地打开

下载仓库后双击 `index.html`，用 Chrome 或 Edge 打开。`assets` 文件夹要和 `index.html` 放在一起。中文字体已打包在 `assets/fonts`，断网也能正常显示。

没有显卡加速的电脑会自动关掉胶片颗粒等装饰效果，保证首页视频能播放。
